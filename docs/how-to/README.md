# How-to guides

Task-oriented recipes for integrating with OpenAura. Each guide assumes the API is reachable and you already understand the basics from the [getting started tutorial](../tutorials/getting-started.md).

| Guide | When to use it |
|---|---|
| [Authenticate requests](authenticate.md) | Headers, admin vs app keys, Bearer auth |
| [Bootstrap an app](bootstrap-an-app.md) | Create apps and first app API keys |
| [Model roles and permissions](model-roles-and-permissions.md) | Define resources, actions, roles, grants |
| [Assign roles to users](assign-roles.md) | Tenant-scoped role assignments |
| [Check access from your backend](check-access.md) | Wire `POST /access/check` into request handlers |
| [Manage API keys](manage-api-keys.md) | Rotate, list, and revoke keys |
| [Handle errors and versioning](errors-and-versioning.md) | Status codes, `X-API-Version`, pagination |
